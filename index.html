ABOUT THE ALGORITHM

Built on fundamental data structures.

HuffZip uses a custom Min Heap to repeatedly extract the two lowest-frequency nodes. These nodes are combined to construct a Huffman Binary Tree, which generates prefix-free binary codes for lossless compression.
