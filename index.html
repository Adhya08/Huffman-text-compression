Computer Science Foundations

How Huffman Coding Works

Invented by David Huffman in 1952, this greedy algorithm is proven to create mathematically optimal prefix codes.

01

Frequency Analysis

Scan the input text and tally the frequency of every unique character. Rare symbols and common letters are separated to inform code lengths.

Time: O(N)
02

Min-Priority Queue

Instantiate a leaf node for each distinct symbol and insert all nodes into a Min Heap ordered by frequency. In ties, insertion order stabilizes priority.

Time: O(K log K)
03

Greedy Tree Construction

Repeatedly pop the two lowest-frequency nodes, merge them into an internal parent node with frequency equal to their sum, and push the parent back into the heap.

K - 1 Merges
04

Prefix Code Assignment

Traverse the binary tree from root to leaf. Assign 0 to every left branch and 1 to every right branch. No code is a prefix of another code.
